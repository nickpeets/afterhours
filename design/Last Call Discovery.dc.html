EVERY SCREEN, EVERY CONTROL
Four people walk through one night in the same room and see four different products. This follows each of them in order, and every button, badge, timer, counter and tray is called out on the control itself — what it does, who can see it, what state it is in here, and what other states it has. Photographic faces throughout, at true device size, so the question "is that window big enough to read a face" answers itself.

Read this instead of the old walkthrough. Last Call Walkthrough is ten screens through one night from a single vantage point; it stays valid on the mid-round exit and the promotion, but this file replaces it as the entry point because role gating — not sequence — is what people get wrong.
